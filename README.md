# Coffee R Us Admin Portal

## Description

A React-based admin dashboard for managing coffee products.

## Features

- View products
- Add products
- Edit products
- Delete products
- Search products
- Responsive design
- CRUD operations
- React Router navigation
- Custom hooks
- Component testing

## Installation
## Run Frontend

npm run dev

## Run Backend

npm run server

## Run Tests

npm run test

## Technologies Used

- React
- Vite
- React Router
- json-server
- Vitest
- React Testing Library

## Future Improvements
